L4D2 RTX V19.6 - Native IES profiles

Copy LM-63 Type C .ies files to:
  <Left 4 Dead 2>\rtx-remix\ies\

The Light Studio profile browser reads this folder. Native IES also accepts an
absolute path, but relative filenames are recommended for portable map settings.

V19_6_Test_Downlight.ies is a small TILT=NONE profile for verifying that the
paired IES-enabled DXVK Remix build and ASI pNext integration work.
